# Wido der Novize

Ein Point-and-Click-Abenteuer im Stil von Monkey Island und Indiana Jones and the Fate of Atlantis – als **eine einzige HTML-Datei** (`index.html`), spielbar im Browser auf Tablet, Handy und Schul-PC. Kein Framework, keine Bilddateien, kein SVG, keine Emojis: Alles wird prozedural per `fillRect` auf ein 320×180-Pixel-Canvas gezeichnet.

**Thema:** Frühmittelalter im Frankenreich, Jahr 802 – vier Kapitel (Urbar/Palimpsest, Ständeordnung, Grundherrschaft und Lehnswesen, Karl der Große und der Elefant Abul Abbas, Handel in Dorestad mit Denaren und Zoll, Klosterleben und das Lorscher Arzneibuch). Zu jedem Kapitel: Rätselkette, freischaltbare Wissenskarten, Abschlusskarte, Diskussionsfrage und Quiz. Hinweis-Knopf zeigt je nach Spielstand den nächsten Schritt; Spielstand in localStorage. Ton: Chiptune per WebAudio.

## Spielen

- Lokal: `index.html` einfach im Browser öffnen.
- Online: GitHub Page unter https://smimueller.github.io/wido-der-novize/

## Steuerung

Verb wählen (Gehe zu, Schau an, Nimm, Benutze, Rede mit, Gib), dann ein oder zwei Dinge anklicken. Tippen = Klicken. Satzzeile zeigt den entstehenden Befehl, z. B. „Benutze Schabeisen mit Pergament“.
